# Implement FY 2026-2027 Salary/Tax Calculation

## Context

Pakistan's Federal Budget 2026-27 was presented on June 12, 2026 (Finance Act 2026),
introducing new salaried income-tax slabs effective **July 1, 2026**. The calculator
currently supports only `2024-2025` and `2025-2026`. We need to add `2026-2027` so
employees can calculate take-home pay under the new rules. Since the new fiscal year
starts in a few weeks, `2026-2027` will become the **default** selected year for new
users (older years remain selectable for comparison).

### Confirmed FY 2026-27 salaried tax slabs (annual taxable income)

| Bracket | Tax |
|---|---|
| 0 – 600,000 | 0% |
| 600,001 – 1,200,000 | 1% of excess over 600,000 |
| 1,200,001 – 2,200,000 | 6,000 + 11% of excess over 1,200,000 |
| 2,200,001 – 3,200,000 | 116,000 + 20% of excess over 2,200,000 |
| 3,200,001 – 4,100,000 | 316,000 + 25% of excess over 3,200,000 |
| 4,100,001 – 5,600,000 | 541,000 + 29% of excess over 4,100,000 |
| 5,600,001 – 7,000,000 | 976,000 + 32% of excess over 5,600,000 |
| Above 7,000,000 | 1,424,000 + 35% of excess over 7,000,000 |

**Key differences vs 2025-26:** lower brackets (≤2.2M) unchanged; the old flat 35%
bracket above 4.1M is split into 29% / 32% / 35% sub-bands; **the 9% surcharge over
10M PKR is abolished** for salaried persons (so no surcharge logic for this year).
EOBI (flat 320) and the 10% tax-free component are unchanged.

Sources: [Express Tribune](https://tribune.com.pk/story/2612818/budget-2026-27-govt-cuts-taxes-ends-surcharge-for-four-salaried-class-income-slabs), [Geo](https://www.geo.tv/latest/668440-pakistan-income-tax-calculator-2026-27-check-your-salary-tax-cut), [Aaj](https://english.aaj.tv/news/330460191/budget-2026-27-government-cuts-income-tax-rates-for-salaried-class), [mytaxcalculator.pk](https://www.mytaxcalculator.pk/).

## Decisions (confirmed with user)
- Default year for new users → **2026-2027** (reset also resets to this).
- Introduce a shared **`TaxYear`** type alias in `types/index.ts` and use it everywhere,
  replacing the inline `'2024-2025' | '2025-2026'` unions.

## Changes

### 1. `types/index.ts`
- Add `export type TaxYear = '2024-2025' | '2025-2026' | '2026-2027';`
- Change `SalaryCalculation.year?` from the inline union to `TaxYear`.

### 2. `utils/calculations.ts`
- Add `calculateTax26to27(amount: number): number` implementing the slab table above.
  Follow the existing `calculateTax25to26` style (subtract lower bound, add fixed base).
  **No surcharge block.**
- Update `calculateTax(amount, year: TaxYear)`: add a branch for `'2026-2027'`
  returning `calculateTax26to27`. Keep existing branches.
- Update `calculateSalaryBreakdown(..., year: TaxYear = '2026-2027')` — change the
  param type to `TaxYear` and default to `'2026-2027'`.
- Import `TaxYear` from `@/types`.

### 3. `components/SalaryCalculator.tsx`
- Replace all inline `'2024-2025' | '2025-2026'` unions with `TaxYear` (import it):
  `selectedYear` state, the `savedYear` validation/guard (line ~63), the cast (line ~64),
  `handleYearChange` param (line ~126), and the `<select onChange>` cast (line ~181).
- Change initial `useState` default (line 38) to `'2026-2027'`.
- Add `'2026-2027'` to the `savedYear` validity check so a stored value loads correctly.
- Change the Reset handler (line ~159) default to `'2026-2027'`.
- Add `<option value="2026-2027">2026-2027</option>` to the dropdown (place it first/top
  so the newest year appears at the top, or after 2025-2026 — order is cosmetic).

### 4. `components/calculator/ResultsSummary.tsx`
- Replace the inline union in props and the `selectedYear` default with `TaxYear`
  (import it). Update the default value to `'2026-2027'` to stay consistent.

### 5. `app/changelog/constant.ts`
- Prepend a new entry (newest first) dated `2026-06-13`, tag `"Feature"`, describing
  the FY 2026-27 tax year: new slabs, the split of the top bracket into 29%/32%/35%,
  and abolition of the 9% surcharge for the salaried class.

## Notes / out of scope
- EOBI stays at flat 320 and the 10% tax-free component is unchanged — not touched.
- `constants/storage.ts` and `salary calculator.html` are unused by the live app and
  are left as-is.

## Verification
1. `npm run dev` (or `yarn dev`) and open http://localhost:3000.
2. Confirm the Tax Year dropdown shows **2026-2027** and it is selected by default.
3. Spot-check calculations against the slabs (gross → taxable = 90% → annualized ×12):
   - Monthly **100,000** → annual taxable 1,080,000 → tax = (1,080,000−600,000)×1% =
     4,800/yr ≈ **400/mo**.
   - Monthly **500,000** → annual taxable 5,400,000 → falls in 4.1M–5.6M band:
     541,000 + (5,400,000−4,100,000)×29% = 541,000 + 377,000 = **918,000/yr** = 76,500/mo.
   - A high salary that previously triggered the 9% surcharge (annual taxable >10M)
     should now show **no surcharge** under 2026-2027 (compare to 2025-2026 which adds 9%).
4. Switch between 2024-2025 / 2025-2026 / 2026-2027 and confirm values change and the
   selection persists across reload (localStorage). Confirm **Reset All** returns the
   dropdown to 2026-2027.
5. `npm run lint` and `npm run build` pass.
